# Game Workbench playable demo

This public repository contains only the exported Godot browser runtime. The main game-workbench source/assets repository remains private. Open the GitHub Pages link to play.

The passcode screen is a casual client-side gate, not confidential hosting. Exported files and game.html are publicly downloadable and the gate can be bypassed. No account passwords or provider keys are included.

The tavern prologue is the default. Begin the evening to meet your companions, make a dialogue choice, and explore the room. Godot is needed to develop the game, not to play this browser build.
